# Output Previews

This folder contains lightweight CSV previews of the entity resolution outputs.
These files are provided for quick inspection and GitHub viewing.

## Files

- `entity_map_preview.csv`
- `entity_edges_evidence_preview.csv`(sample)
- `veridion_with_entity_id_preview.csv`(sample)

The previews are intentionally reduced in size:
- `entity_map_preview.csv` → full mapping table
- `entity_edges_evidence_preview.csv` →sample of evidence edges
- `veridion_with_entity_id_preview.csv`→ sampled updated dataset

## Full Outputs

The complete Parquet outputs are available separately as compressed archives:

- `entity_map_parquet.zip`
- `entity_edges_evidence_parquet.zip`
- `veridion_with_entity_id_parquet.zip`

These files are available in the **GitHub Releases section of this repository**  
under the release:

**Full Entity Resolution Outputs**
